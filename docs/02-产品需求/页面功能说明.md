## 3. 产品功能

当前产品数据来自 `src/data/site.js` 的 `products`：

- 云台智管 ERP
- 云台智造 MES
- 云台 DataHub
- 云台智策 BI
- 云台 Agent

产品卡片当前统一跳转到 `/product`。`/product/:id` 当前会重定向到 `/product`，后续如需 SEO 和单产品分享，应恢复单详情页。

## 4. 案例功能

当前案例数据来自 `src/data/site.js` 的 `cases`：

- 天山材料｜商混MVP平台建设
- 南方新材料｜集团数字化平台建设
- 海南核电｜核电预警系统建设
- 中交二航局｜工程建设信息化平台

案例卡片当前统一跳转到 `/case`。`/case/:id` 当前会重定向到 `/case`，后续如需 SEO 和单案例分享，应恢复单详情页。

## 5. 联系表单

当前联系表单为静态 UI，计划字段包括：

- `contactName`
- `companyName`
- `email`
- `phone`
- `demandType`
- `demandContent`
- `sourcePage`

提交接口建议见 `docs/04-接口设计/接口对接总览.md`。
