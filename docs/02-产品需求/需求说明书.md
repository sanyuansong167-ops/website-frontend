## 1. 总体目标

建设武汉云台数据有限公司官网前台页面，展示公司品牌、产品能力、AI 战略、行业案例、企业实力、发展历程和联系方式，并为后续后端维护内容预留接口化能力。

## 2. 当前阶段范围

当前阶段需要完成：

- 官网前台页面结构和视觉展示。
- 首页核心模块展示。
- 产品、案例、时间轴等内容数据化。
- Portal 接口接入和本地数据兜底。
- 联系我们表单前端交互和校验。
- PC、平板、移动端响应式适配。
- 基础 SEO 和上线信息。
- 构建和部署能力。

当前阶段不要求完成：

- 后端服务开发。
- 数据库开发。
- 后台管理系统完整 CRUD。
- 登录权限系统。
- 真实文件上传。
- 多语言。
- 完整新闻系统。

## 3. 功能优先级

| 优先级 | 功能 |
| --- | --- |
| P0 | 首页、产品汇总、案例汇总、关于我们、联系方式、Portal 基础接口、联系表单、响应式、构建 |
| P1 | 单产品详情、单案例详情、异常状态、图片兜底、首页组件拆分 |
| P2 | AI 能力中心、招聘页、新闻动态、多语言、动画增强 |

## 4. 前后端分工

| 角色 | 负责内容 |
| --- | --- |
| 前端 | 页面展示、路由、响应式、接口调用、字段映射、表单校验、构建产物 |
| 后端 | 数据库、内容管理接口、表单提交接口、图片上传、后台管理和数据校验 |
| 双方 | 字段命名、接口路径、响应结构、错误码、排序、上下架、图片资源规范 |

## 5. 验收标准

| 类型 | 标准 |
| --- | --- |
| 页面 | 首页、产品页、案例页可访问，主要模块展示完整 |
| 数据 | 接口成功时使用接口数据，接口失败时使用本地兜底 |
| 表单 | 必填、邮箱、电话基础校验和提交反馈可用 |
| 联调 | 字段映射清晰，异常和空数据不导致页面崩溃 |
| 构建 | `npm install`、`npm run dev`、`npm run build` 可用 |
| 上线 | SEO、备案、正式联系方式、图片资源和部署回退配置已确认 |
