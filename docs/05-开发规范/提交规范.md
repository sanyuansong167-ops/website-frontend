## 1. 提交消息建议

```text
docs: 重构项目文档体系
feat: 接入产品列表接口
fix: 修复导航锚点高亮
refactor: 拆分首页数据结构
chore: 更新构建配置
```

## 2. 提交前检查

| 类型 | 检查 |
| --- | --- |
| 代码修改 | `npm run build` |
| 接口修改 | 更新接口总览、字段映射、联调说明 |
| 字段修改 | 更新字段说明书、Mock 数据规范 |
| 页面修改 | 更新页面结构说明、页面功能说明 |
| 上线信息修改 | 更新上线检查清单、README |

## 3. 文档提交要求

文档提交应说明：

- 新增了哪些主文档。
- 合并了哪些旧文档。
- 哪些内容标记为待确认。
- 是否修改业务代码。
