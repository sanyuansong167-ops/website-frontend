## 1. 基本原则

- 优先沿用 Vue 3 + Vite + Vue Router + Axios + CSS。
- 不因单个任务擅自引入大型 UI 框架、状态管理库或构建体系。
- 页面表现不应因数据化改造发生视觉回退。
- 字段映射应集中处理，避免后端字段散落在模板中。
- 文档-only 任务不得修改业务代码。

## 2. Vue 规范

| 场景 | 规则 |
| --- | --- |
| 页面组件 | 放在 `src/views/` |
| 通用组件 | 放在 `src/components/` |
| 组合逻辑 | 简单逻辑可留在页面，复杂逻辑再抽离 |
| 接口数据 | 先映射为页面稳定字段再渲染 |
| 异常处理 | 接口失败时必须有兜底或提示 |

## 3. 数据规范

- 本地兜底数据当前统一维护在 `src/data/site.js`。
- 后续可按业务拆分为 `home.js`、`products.js`、`cases.js`、`about.js`。
- 新增数据字段时同步更新 `docs/03-前端设计/字段说明书.md`。
- 修改接口字段时同步更新 `docs/04-接口设计/API字段映射表.md`。

## 4. 构建要求

涉及代码修改后应运行：

```bash
npm run build
```

如果未运行，需要在交付说明中写明原因。
