> - 所属阶段：持续维护

> - 本文不用于：定义具体提交消息格式

> - 关键词：Git，分支，协作

## 1. 分支建议

| 类型 | 建议命名 |
| --- | --- |
| 功能 | `feature/<topic>` |
| 修复 | `fix/<topic>` |
| 文档 | `docs/<topic>` |
| AI 协作 | `codex/<topic>` |

## 2. 变更范围

- 每次提交应聚焦一个目标。
- 文档重构可以作为独立提交，不与业务代码混合。
- 接口字段变更应同时提交相关文档。
- 不要在无明确原因时提交 `dist/`、日志文件或临时文件。

## 3. 协作规则

- 修改前先查看 `git status`。
- 不回滚他人未确认的改动。
- 遇到文档和代码冲突时，以源码为事实来源，并在文档中标记差异。
