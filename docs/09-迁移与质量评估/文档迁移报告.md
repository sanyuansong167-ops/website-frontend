## 4. 主要改进点

- 将旧文档中重复的字段、接口和任务说明拆分到唯一主文档。
- 将“当前已接接口”和“建议接口”分开，降低联调误判。
- 将字段总表集中到 `字段说明书.md`，避免字段散落。
- 为 AI 新增项目上下文、开发规范和提示词规范。
- 将上线检查迁移到部署运维层。

## 5. 未来优化建议

### 文档优化方向

- 为每个目录补充更细的 README 索引，当前已有全局索引可先使用。
- 后续每次接口变更都同步更新 API 字段映射表。
- 每次版本发布后补充迭代记录。

### 前后端联调方向

- 尽快确认产品、案例、关于我们和联系表单接口路径。
- 为错误码、分页、排序、上下架建立统一规则。
- 建议后端返回 `sortOrder`、`isActive`、`createdAt`、`updatedAt`。

### AI 协作方向

- 后续开发任务直接引用任务编号。
- 每次 AI 改动后要求说明修改文件、验证结果和文档同步情况。
- 对复杂任务先生成小型任务输入包，避免一次性跨太多模块。
