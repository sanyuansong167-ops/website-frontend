## 1. 当前组件

| 组件 | 职责 | 主要输入 |
| --- | --- | --- |
| `SiteHeader.vue` | 全站顶部导航、站点配置、SEO 基础设置 | Portal 接口、本地 `navigation`、`siteConfig` |
| `FooterSection.vue` | 全站页脚 | 当前静态内容 |
| `SectionTitle.vue` | 模块标题 | `tag`、`title`、`desc` |
| `IconBox.vue` | lucide 图标包装 | `name`、`color` |
| `Feature.vue` | AI 能力展示卡片 | `icon`、`color`、`en`、`title`、`text` |

## 2. 组件边界

- 页面级组件放在 `src/views/`。
- 全站复用组件放在 `src/components/`。
- 新增首页模块组件时建议放在 `src/components/home/`。
- 组件不要直接依赖后端原始字段，字段映射应放在 API 层或页面映射函数。
- 通用组件只接收展示所需 props，不承担接口请求职责。

## 3. 新增组件规则

| 场景 | 建议 |
| --- | --- |
| 一个模块超过 150 行且含多段结构 | 拆成模块组件 |
| 多个页面重复展示同类卡片 | 抽成复用组件 |
| 只是当前页面一次性布局 | 保留在页面组件内 |
| 后端字段需要转换 | 不放入展示组件，放在 API 层或页面层 |

## 4. 命名规则

| 类型 | 规则 | 示例 |
| --- | --- | --- |
| 组件文件 | PascalCase | `SiteHeader.vue` |
| 展示组件 props | camelCase | `iconName`、`color` |
| 页面模块组件 | 业务名 + Section/Card | `ProductSection.vue` |
| CSS class | kebab-case | `product-card` |

## 5. 交互状态

新增接口化组件时应考虑：

- loading
- empty
- error
- fallback
- disabled
- image error

当前项目这类状态仍需补齐，详见 `docs/07-项目管理/开发任务清单.md`。
