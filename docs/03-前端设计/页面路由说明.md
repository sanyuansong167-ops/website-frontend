## 1. 当前路由配置

| 路由名称 | 路由地址 | 页面组件 | 权限要求 | 页面说明 |
| --- | --- | --- | --- | --- |
| home | `/` | `Home.vue` | 无 | 官网首页 |
| products redirect | `/products` | redirect | 无 | 重定向到 `/#products` |
| product-detail | `/product` | `ProductDetail.vue` | 无 | 产品详情汇总页 |
| product-id redirect | `/product/:id` | redirect | 无 | 当前重定向到 `/product` |
| cases redirect | `/cases` | redirect | 无 | 重定向到 `/#cases` |
| case-detail | `/case` | `CaseDetail.vue` | 无 | 案例详情汇总页 |
| case-id redirect | `/case/:id` | redirect | 无 | 当前重定向到 `/case` |

## 3. 滚动行为

当前 `scrollBehavior` 规则：

- 如果目标路由有 `hash`，滚动到对应元素。
- 顶部偏移为 `88px`。
- 使用平滑滚动。
- 无 hash 时滚动到页面顶部。

## 5. 部署注意事项

当前路由使用 `createWebHistory()`。生产环境如果直接刷新 `/product` 或 `/case`，服务器必须回退到 `index.html`，否则可能出现 404。
