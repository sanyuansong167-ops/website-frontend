## 3. Header 结构

`SiteHeader.vue` 负责：

- 展示站点 Logo、名称和 slogan。
- 通过 `getSiteConfig()` 获取站点配置。
- 通过 `getNavigation()` 获取导航。
- 将后端导航字段映射为前端菜单字段。
- 支持锚点滚动、高亮和外链。
- 接口失败时使用 `src/data/site.js` 的 `navigation` 和 `siteConfig` 兜底。

## 4. Footer 结构

`FooterSection.vue` 当前为静态内容，包含：

- 品牌说明。
- 快速链接。
- 服务领域。
- 联系方式。
- 版权和备案号占位。

后续如进入 CMS 维护，应抽离为站点配置或 Footer 接口。
