## 1. 文档目标

本目录用于让人类开发者、后端联调人员、测试人员和 AI 助手快速理解 Yuntai Frontend。重构后的文档遵循四个原则：

- 一个主题只有一个主文档。
- README 只做总览和导航，不堆积细节。
- 字段、接口、Mock、页面、路由分开维护，但保持交叉引用。
- 所有待确认内容必须标记为“待确认”，不得写成已完成事实。

## 6. 维护规则

| 变更类型 | 必须同步 |
| --- | --- |
| 新增页面 | 页面功能说明、页面结构说明、页面路由说明、字段说明书、AI项目上下文 |
| 修改路由 | 页面路由说明、README 文档导航、上线检查清单 |
| 修改接口 | 接口对接总览、API字段映射表、联调说明、字段说明书 |
| 修改字段 | 字段说明书、API字段映射表、Mock数据规范 |
| 修改 Mock | Mock数据规范、字段说明书、开发任务清单 |
| 上线信息变化 | 环境配置说明、打包发布、上线检查清单、README |
| 阶段状态变化 | 开发计划、开发任务清单、迭代记录、AI项目上下文 |

## 7. 文档冲突处理

如文档与代码冲突，以当前源码和配置为准；如旧文档之间冲突，以本次重构后的主文档为准；如源码事实无法确认，标记为“待确认”。
