## 1. Codex 开发提示词

```text
请先阅读 README.md、docs/00-文档体系说明.md、docs/08-AI协作文档/AI项目上下文.md。
本次只处理 [任务编号/任务名称]。
禁止修改无关业务代码。
如涉及字段、接口或页面变更，请同步更新对应 docs。
完成后说明修改文件、验证结果和未完成风险。
```

## 2. 接口联调提示词

```text
请根据 docs/04-接口设计/接口对接总览.md 和 API字段映射表.md，

```

## 3. 页面开发提示词

```text

```
