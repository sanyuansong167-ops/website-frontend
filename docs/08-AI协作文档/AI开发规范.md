## 1. 通用规则

- 修改前先确认任务类型：文档、页面、字段、接口、样式、部署。
- 优先读取主文档，不要依赖旧文档片段。
- 不跨越任务范围做大重构。
- 不删除有效内容，迁移时要保留语义。
- 不把待确认能力写成已完成。

## 2. 新增页面规则

新增页面时同步：

- `docs/02-产品需求/页面功能说明.md`
- `docs/03-前端设计/页面结构说明.md`
- `docs/03-前端设计/页面路由说明.md`
- `docs/03-前端设计/字段说明书.md`
- `docs/08-AI协作文档/AI项目上下文.md`

## 3. 新增接口规则

新增接口时同步：

- `docs/04-接口设计/接口对接总览.md`
- `docs/04-接口设计/API字段映射表.md`
- `docs/04-接口设计/联调说明.md`
- `docs/03-前端设计/字段说明书.md`

## 4. 新增字段规则

新增字段时必须说明：

- 字段名。
- 中文名称。
- 类型。
- 是否必填。
- 默认值。
- 来源。
- 所属页面。
- 关联接口。
- 说明。

## 5. 验证规则

| 修改类型 | 验证 |
| --- | --- |
| 文档-only | 检查目录、链接、迁移关系 |
| 代码修改 | `npm run build` |
| 接口修改 | 接口失败兜底 |
| 页面修改 | 桌面和移动端基本检查 |
