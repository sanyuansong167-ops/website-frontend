# 武汉云台数据有限公司官网前端任务清单

本文档用于记录武汉云台数据有限公司官网前端项目的具体开发任务。任务来源包括 `docs/前端需求.md`、`docs/前端开发阶段.md`、`docs/前端字段与接口规范说明书.md` 和 `docs/字段优化建议.md`。

本文档负责回答“现在具体做哪些任务、涉及哪些文件、做到什么程度算完成”。

## 1. 当前推荐执行任务

当前优先执行：

```text
T001 首页硬编码内容抽离
```

执行完成后继续：

```text
T002 首页 Mock 数据拆分
T003 产品数据字段统一
T004 案例数据字段统一
```

## 2. 任务状态说明

| 状态 | 含义 |
|---|---|
| 未开始 | 尚未开发 |
| 进行中 | 正在开发 |
| 待联调 | 前端完成，等待后端或接口 |
| 待验收 | 已完成，等待确认 |
| 已完成 | 已通过验收 |
| 暂缓 | 当前阶段不做 |

## 3. 任务维护规则

- 开始开发时，将任务状态改为“进行中”。
- 前端代码完成但依赖后端接口时，将状态改为“待联调”。
- 自测通过后，将状态改为“待验收”。
- 用户确认或验收标准全部满足后，将状态改为“已完成”。
- 如果任务范围变化，需要同步更新本文档和相关需求/阶段文档。
- 每个任务完成后，需要保证 `npm run build` 可通过，除非任务本身不涉及代码。
