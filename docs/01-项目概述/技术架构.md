## 1. 技术栈

| 类型 | 当前使用 |
| --- | --- |
| 框架 | Vue 3 |
| 构建 | Vite |
| 路由 | Vue Router，`createWebHistory()` |
| 请求 | Axios |
| 图标 | lucide-vue-next |
| 样式 | 原生 CSS，`global.css` 与 `home-hero.css` |
| 语言 | JavaScript，局部 SFC 使用 `lang="ts"` |
| 状态管理 | 暂无 Pinia/Vuex |

## 2. 目录职责

| 目录或文件 | 职责 |
| --- | --- |
| `src/main.js` | 创建 Vue 应用、挂载 Router、引入全局样式 |
| `src/App.vue` | 根组件，仅渲染 `router-view` |
| `src/router/index.js` | 全站路由和滚动行为 |
| `src/views/` | 页面级组件 |
| `src/components/` | Header、Footer、标题、图标和展示组件 |
| `src/api/http.ts` | Axios 实例，使用 `VITE_API_BASE_URL` |
| `src/api/portal.ts` | Portal 接口封装、响应解包、异常处理 |
| `src/data/site.js` | 本地兜底数据：产品、案例、时间轴、Hero、导航、指标、荣誉、站点配置 |
| `src/assets/styles/` | 全局样式和首页视觉样式 |

## 3. 数据流

```text
Portal 后端接口
  ↓
src/api/http.ts
  ↓
src/api/portal.ts
  ↓
页面或组件内映射函数
  ↓
Vue 响应式状态
  ↓
页面展示
```

接口失败时：

```text
请求失败
  ↓
console.error 记录
  ↓
继续使用 src/data/site.js 默认数据
  ↓
避免首屏空白
```

## 4. Vite 代理

`vite.config.mjs` 当前配置：

```js
server: {
  proxy: {
    '/portal': {
      target: 'http://localhost:8080',
      changeOrigin: true,
    },
  },
}
```

开发环境中，前端访问 `/portal/api/site/...` 时会代理到本地后端 `http://localhost:8080`。

## 5. 当前接口层特点

- `src/api/portal.ts` 会识别后端返回 HTML 的异常情况，用于提示代理或后端路由问题。
- 支持外层 `{ code, message, data }` 解包。
- `code` 支持 `0`、`200`、`success` 等成功值。
- 如果接口直接返回数据而非外层 `data`，也会作为有效数据返回。

## 6. 架构风险

| 风险 | 影响 | 建议 |
| --- | --- | --- |
| `Home.vue` 仍包含大量硬编码内容 | 内容维护成本高 | 按模块抽离数据 |
| 产品和案例仍使用旧字段 | 后端联调需映射 | 保持 API 层字段转换 |
| 局部 `lang="ts"` 但无完整 TS 工程约束 | 类型收益有限 | 后续统一 TS 策略 |
| history 路由需要服务端回退 | 部署刷新可能 404 | 部署时配置 `index.html` fallback |
