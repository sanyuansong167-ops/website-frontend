```text

第三阶段：前后端联调准备 -> 部分开始
```

## 6. 推荐推进顺序

1. 抽离首页硬编码内容。
2. 统一产品、案例、时间轴字段。
3. 完善现有 Portal API 和本地兜底映射。
4. 补齐联系表单绑定、校验和提交。
5. 恢复单产品、单案例详情。
6. 补齐 loading、empty、error 和图片兜底。
7. 与后端确认接口字段后进入联调。
8. 补齐 SEO、备案、正式联系方式和上线检查。
