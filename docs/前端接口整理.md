# 前端接口整理

| 接口 | 方法 | 前端封装 | 使用组件 | Mock 兜底 |

## 接口字段映射

### 站点配置 `/portal/api/site/config`

后端返回字段：

| 后端字段 | 前端使用字段 | 说明 |
| --- | --- | --- |
| `siteTitle` | `siteConfig.name`、`siteConfig.seo.title` | 站点名称与页面标题 |
| `seoKeywords` | `siteConfig.seo.keywords` | SEO keywords meta |
| `seoDescription` | `siteConfig.seo.description` | SEO description meta |
| `brandSlogan` | `siteConfig.slogan` | 品牌副标题，优先使用 |
| `brandTagline` | `siteConfig.slogan` | `brandSlogan` 为空时兜底 |
| `logoLightUrl` | `siteConfig.logo` | Logo 图片，优先使用 |
| `logoDarkUrl` | `siteConfig.logo` | `logoLightUrl` 为空时兜底 |

前端不再优先读取旧字段：`logo`、`logoUrl`、`name`、`siteName`、`companyName`、`slogan`。

### 导航 `/portal/api/site/navigation`

后端返回字段：

| 后端字段 | 前端使用字段 | 说明 |
| --- | --- | --- |
| `id` | `key`、分组菜单兜底 `activeId` | 菜单唯一标识 |
| `menuName` | `label` | 顶部导航显示名称 |
| `targetType` | `targetType` | 菜单跳转类型 |
| `routePath` | `href`、`routeLocation` | 内部路由路径或页面锚点所在路径 |
| `anchorCode` | `href`、`routeLocation.hash`、`activeId` | 页面锚点 code |
| `externalUrl` | `href` | 外部链接地址 |
| `openInNewTab` | `target`、`rel` | 外链是否新窗口打开 |
| `children` | `submenu` | 分组或子菜单数据，递归保留 |

`targetType` 支持规则：

| 类型 | 前端行为 |
| --- | --- |
| `PAGE_ANCHOR` | 使用 `routePath` 与 `anchorCode` 组合为 Vue Router 跳转目标，默认路径为 `/` |
| `INTERNAL_ROUTE` | 使用 `routePath` 作为 Vue Router 内部路由 |
| `EXTERNAL_LINK` | 使用 `externalUrl` 作为普通链接，按 `openInNewTab` 决定是否新窗口打开 |
| `GROUP` | 作为分组菜单保留，不主动跳转，子级数据保存在 `submenu` |

### 首页 Banner `/portal/api/site/home-banner`

后端返回字段：

| 后端字段 | 前端使用字段 | 说明 |
| --- | --- | --- |
| `mainTitle` | `hero.title` | 首页主标题 |
| `subTitle` | `hero.subtitle` | 首页副标题 |
| `backgroundImageUrl` | `hero.backgroundImage` | 首页背景图 |

接口返回数组时，前端取第一条作为首页 Banner。

### 首页指标 `/portal/api/site/home-metrics`

后端返回字段：

| 后端字段 | 前端使用字段 | 说明 |
| --- | --- | --- |
| `value` | `metric.value` | 指标数值 |
| `unit` | `metric.unit` | 指标单位 |
| `description` | `metric.description` | 指标说明 |

前端会过滤缺少 `value` 或 `description` 的项。

### 荣誉资质 `/portal/api/site/honors`

后端返回字段：

| 后端字段 | 前端使用字段 | 说明 |
| --- | --- | --- |
| `name` | `honor.name` | 荣誉名称 |
| `iconUrl` | `honor.iconUrl` | 荣誉图标 |

前端会过滤缺少 `name` 的项；`iconUrl` 为空时使用页面内默认图标。

## 后续联调注意事项

1. Portal 接口统一通过 `src/api/portal.ts` 封装，接口响应会自动解包外层 `data`。
2. 任一接口请求失败时，页面继续使用 `src/data/site.js` 的默认数据，避免首屏空白。
3. 导航联调时请确认 `targetType` 枚举值为 `PAGE_ANCHOR`、`INTERNAL_ROUTE`、`EXTERNAL_LINK`、`GROUP`。
4. `PAGE_ANCHOR` 建议提供与页面 section id 一致的 `anchorCode`，例如 `products`、`cases`、`about`、`contact`。
5. 外链菜单请同时提供完整 `externalUrl`；如需新窗口打开，请返回 `openInNewTab: true`。
6. 站点配置请使用新字段返回，不依赖旧字段兼容。
