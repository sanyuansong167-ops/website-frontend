## 1. 安装依赖

```bash
npm install
```

## 2. 启动开发环境

```bash
npm run dev
```

脚本实际执行：

```bash
vite --host 0.0.0.0
```

访问地址以终端输出为准，通常为：

```text
http://localhost:5173
```

## 3. 本地后端联调

当前 Vite 代理：

```text
/portal -> http://localhost:8080
```

如需联调 Portal 接口，后端服务应在本地 `8080` 端口提供接口。
