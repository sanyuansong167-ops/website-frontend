## 1. 生产构建

```bash
npm run build
```

构建产物：

```text
dist/
```

## 2. 本地预览

```bash
npm run preview
```

脚本实际执行：

```bash
vite preview --host 0.0.0.0
```

## 3. 发布方式

`dist/` 可部署到：

- Nginx
- 静态资源服务器
- 对象存储
- 静态站点平台

## 4. 路由回退

当前使用 Vue Router history 模式。服务器需配置：

```text
任意前端路由刷新 -> 返回 index.html
```

否则刷新 `/product`、`/case` 等路径可能 404。
