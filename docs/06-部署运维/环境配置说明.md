## 1. 当前环境变量

`src/api/http.ts` 使用：

```text
VITE_API_BASE_URL
```

用于 Axios `baseURL`。

## 2. 建议补充环境变量

```env
VITE_API_BASE_URL=
VITE_USE_MOCK=true
```

说明：

| 变量 | 用途 | 当前状态 |
| --- | --- | --- |
| `VITE_API_BASE_URL` | 指定接口基础地址 | 已被代码读取 |
| `VITE_USE_MOCK` | 控制本地 Mock 或真实接口 | 建议新增 |

## 3. 本地代理

开发环境中，`/portal` 会代理到：

```text
http://localhost:8080
```

生产环境是否保留 `/portal` 前缀和代理策略，需要后端与部署方确认。

## 4. 安全规则

- 不在前端仓库提交数据库账号、密码、RDS 地址。
- 不在文档中记录生产密钥。
- 生产接口地址由部署方或环境变量注入。
