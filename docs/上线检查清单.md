## 1. 状态说明

| 状态 | 含义 |
|---|---|
| 未完成 | 尚未处理 |
| 待确认 | 需要用户、运营、后端或部署方确认 |
| 待检查 | 已具备条件，等待检查 |
| 已完成 | 已确认通过 |
