# 字段优化建议

本文档记录当前项目字段命名和接口化过程中建议优化的地方。仅作为后续迭代参考，当前未改动业务代码。

## 1. 当前字段命名不统一

| 当前字段 | 所在位置 | 问题 | 建议 |
|---|---|---|---|
| `title` | product | 产品名称使用 `title`，语义偏标题 | API 层改为 `name` |
| `sub` | product | 缩写不直观 | 改为 `subtitle` |
| `desc` | product/case | 缩写不直观 | 改为 `description` |
| `img` | case | 缩写不直观 | 改为 `imageUrl` |
| `features` | product | 可以更贴近页面语义 | 改为 `coreFunctions` |
| `quote` | case | 当前可保留，但含义偏展示 | 可视业务改为 `summary` 或保留 `quote` |

## 2. 时间轴数据结构建议

当前：

```js
['2015', '公司成立', '武汉云台数据有限公司成立，落户东湖科技园']
```

建议：

```js
{
  year: '2015',
  title: '公司成立',
  description: '武汉云台数据有限公司成立，落户东湖科技园',
  isCurrent: false,
  sortOrder: 10
}
```

## 3. 联系表单字段建议

当前 UI 文案与联调字段建议不完全一致。

| 当前 UI | 建议前端字段 | 后端字段 | 数据库字段 |
|---|---|---|---|
| 姓名 | contactName | contactName | contact_name |
| 公司 | companyName | companyName | company_name |
| 邮箱 | email | email | email |
| 电话 | phone | phone | phone |
| 需求描述 | demandContent | demandContent | demand_content |
| 当前无 | demandType | demandType | demand_type |

## 4. API 分层建议

建议后续新增：

```text
src/api/home.js
src/api/products.js
src/api/cases.js
src/api/contact.js
src/api/jobs.js
```

前端页面不要直接依赖后端字段，可在 API 层做字段转换，保持 UI 组件字段稳定。

## 5. 页面缺口

| 页面 | 当前状态 | 建议 |
|---|---|---|
| AI能力中心 | 仅有首页 AI战略模块 | 后续新增 `/ai-center` |
| 公司招聘 | 未实现 | 后续新增 `/jobs` |
| 单产品详情 | 当前统一 `/product` 汇总页 | 如有 SEO 需求，可恢复 `/product/:id` |
| 单案例详情 | 当前统一 `/case` 汇总页 | 如有 SEO 需求，可恢复 `/case/:id` |

## 6. 数据库字段建议

数据库建议使用 snake_case：

```text
company_name
contact_name
demand_type
demand_content
image_url
sort_order
is_active
created_at
updated_at
```

API 返回建议使用 camelCase：

```text
companyName
contactName
demandType
demandContent
imageUrl
sortOrder
isActive
createdAt
updatedAt
```
